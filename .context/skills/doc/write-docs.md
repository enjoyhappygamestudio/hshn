# Skill: Viết tài liệu

## Quy trình

1. Xác định loại tài liệu: README, API docs, changelog
2. Thu thập thông tin từ code / spec
3. Viết template, giữ ngắn gọn, tiếng Việt
4. Review: đúng chính tả, dễ hiểu, đủ thông tin

## README structure
```
# Tên dự án
## Tổng quan
## Cài đặt
## Cấu trúc
## API
## Đóng góp
```

## Changelog structure
```
## [1.0.0] - 2025-01-01
### Added
### Changed
### Fixed
```
