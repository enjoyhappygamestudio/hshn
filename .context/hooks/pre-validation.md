# Hook: Pre-validation

Kích hoạt TRƯỚC khi tạo code cho màn hình hoặc tính năng mới.

## Checklist

- [ ] Đã đọc screen blueprint? (nếu là màn hình)
- [ ] Đã xác định data model?
- [ ] Đã xác định API endpoints?
- [ ] Đã xác định states (loading, empty, error, success)?
- [ ] Đã kiểm tra brand token consistency?
- [ ] Đã xác định navigation flow?
- [ ] Đã xác định test strategy?
