# T-005 — Coverage requirements

## Minimum coverage

| Module | Coverage |
|---|---|
| Business logic (utils, calculations) | 100% |
| Hooks | 90% |
| Store (Zustand) | 90% |
| Components | 80% |
| Screens | 70% |
| Admin screens | 75% |

## Critical paths (must test)

- Tính tổng tiền, discount, phí ship
- Validate thời gian giao hàng
- Áp dụng voucher (percent, fixed, shipping)
- Thêm/xóa/sửa giỏ hàng
- Chuyển đổi trạng thái đơn hàng
