# I-002 — Phân tích root cause

Khi sửa lỗi, tạo RCA report:

```markdown
## RCA Report

### Bug
{Mô tả bug}

### Steps to reproduce
1. ...

### Root cause
{Phân tích nguyên nhân gốc}

### Fix
{Mô tả fix, link file + line}

### Regression test
{Mô tả test ngăn tái diễn}

### Prevention
{Cách phòng ngừa trong tương lai}
```
